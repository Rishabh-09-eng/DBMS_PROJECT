# 🔨 Online Auction Management System

> A web-based auction platform where users can list products, participate in bidding, and purchase items through an online auction process.

## 📌 About The Project

The **Online Auction Management System** is a web-based application developed as part of our Database Management System (DBMS) project.

The platform allows users to participate in online auctions, sellers to list their products, and buyers to place bids. It manages the auction lifecycle, from product listing and bidding to winner selection and transaction management.

## 🎯 Project Objectives

- 👤 Manage user registration and login.
- 📦 Allow sellers to list and manage products.
- 🔨 Enable buyers to participate in online bidding.
- 🏆 Select auction winners based on the highest valid bid.
- 💳 Maintain transaction and payment records.
- 🗄️ Implement database management concepts in a real-world application.

## ⚙️ Installation & Setup

Follow these steps to run the project on your local machine.

### 📋 Prerequisites

- XAMPP installed on your system.
- Git installed.
- A web browser.

### 🚀 Step 1: Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/ronakkumawat9680/DBMS_PROJECT.git
```

### 📂 Step 2: Move the Project

- Navigate to the cloned repository.
- Copy the project folder into the XAMPP `htdocs` directory.

### ▶️ Step 3: Start XAMPP

- Open the XAMPP Control Panel.
- Start **Apache**.
- Start **MySQL**.

### 🗄️ Step 4: Create the Database

1. Open your browser and visit:

   ```text
   http://localhost/phpmyadmin/
   ```

2. Click on **New** to create a database.
3. Enter the database name:

   ```text
   auction_system
   ```

4. Click **Create**.

### 📥 Step 5: Import the Database

1. Select the newly created `auction_system` database.
2. Open the **Import** tab.
3. Choose the SQL file from the project's `database` folder.
4. Import the `auction_system.sql` file.
5. Wait for the successful import confirmation.

### 🌍 Step 6: Run the Project

Open your browser and visit:

```text
http://localhost/DBMS_PROJECT/
```

🎉 **Congratulations! Your Online Auction Management System is now running locally.**
